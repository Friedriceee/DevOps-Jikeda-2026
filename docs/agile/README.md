and presentation should link to this folder rather than duplicating different
versions of the same sprint records.

## Evidence convention

Each record links to executable evidence where the repository has it. The
team must replace any `team confirmation required` note with the final GitHub
issue, pull request, CI run, screenshot or report-page reference before
submission. No estimate or completion date is invented in this package.

## Definition of done for this package

- The backlog and user-story IDs use the same names as the report and code.
- Every sprint has a plan, review and retrospective.
- Burndown totals come from the team's agreed sprint board or report.
- Completed work points to tests, PRs or demo evidence.
- Open risks are labelled as open rather than described as completed.
